# Google Form Clone (HTML & CSS Only)

This is a simple, static Google Form-like landing page built using **only HTML and CSS**. It collects basic user information and follows clean UI practices for better readability and responsiveness.

## 🧾 Features

- Collects user inputs for:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (dropdown)
  - Gender (radio buttons)

## 🎨 Design Highlights

- Clean layout with centered form
- Different background for the form container
- Smooth hover effect on the submit button
- Subtle box-shadow for minimalistic depth

## 🛠️ Built With

- HTML5
- CSS3 (No JavaScript)
